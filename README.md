# Presentación sobre IA

Este repositorio ahora puede abrirse fácilmente en un host local con una página de inicio simple.

## Ejecutar en localhost

Desde la raíz del proyecto, ejecuta:

```bash
python3 -m http.server 8000
```

Luego abre esta URL en tu navegador:

```text
http://localhost:8000
```

## Archivos principales

- `index.html`: página de inicio para el host local.
- `presentacion_ia.pptx`: presentación descargable.
